# HAL

A HAL 9000-inspired AI chat app, with an offline mode powered by WebLLM.

![HAL screenshot](<HAL - screenshot.png>)

## Run it

Download `HAL Standalone.html`, `hal.html` and open it in your web browser.

## Offline mode

`HAL Offline` runs a local Llama 3.2 3B model with WebLLM. The model weights (about 2 GB) are not in this repo. Run `Get HAL Brain.bat` to download them into `HAL Offline/brain/`, then start HAL with `Start HAL.bat`.
